Vad är Bootstrap?

Bootstrap är ett CSS-ramverk med öppen källkod som används för att skapa responsiva webbplatser. Ramverket erbjuder färdiga komponenter, CSS-klasser och ett grid-system för att strukturera innehåll.

Utvärdering av Bootstrap

Fördelar

  • Enkelt att komma igång med.
  • Många färdiga komponenter.
  • Bra stöd för responsiv design.
  • Omfattande dokumentation.

Nackdelar

  • Webbplatser kan få ett liknande utseende.
  • Det finns många CSS-klasser att lära sig.
  • Ramverket innehåller kod som inte alltid behövs.
  • Unik design kan kräva egen CSS.

Mina upplevelser

Jag upplevde att Bootstrap var relativt enkelt att använda eftersom det finns färdiga klasser för exempelvis tabeller, formulär och knappar. Det gick snabbt att skapa en responsiv layout utan att behöva skriva egen CSS. Däremot behöver man lära sig vad de olika klasserna betyder.
