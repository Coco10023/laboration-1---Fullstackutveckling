GitHub Pages

GitHub Pages är en publiceringsplattform som gör det möjligt att publicera statiska webbplatser direkt från ett repository på GitHub. Plattformen använder Git för versionshantering och kräver inte FTP eller SFTP för publicering.

GitHub Pages officiella webbplats

Kodstöd

GitHub Pages har stöd för statiska webbplatser som använder HTML, CSS och JavaScript. Plattformen har även stöd för statiska webbplatsgeneratorer som Jekyll.

Däremot finns inget direkt stöd för serverbaserade programmeringsspråk som PHP, Python eller C#. Plattformen erbjuder inte heller någon egen databas.

Kostnad

GitHub Pages kan användas kostnadsfritt med offentliga repositories. Det gör plattformen lämplig för studenter, mindre webbplatser och personliga projekt.

Fördelar och nackdelar

Fördelar

  • Gratis för offentliga repositories.
  • Ingen FTP eller SFTP behövs.
  • Integrerad versionshantering med Git.
  • Automatisk publicering vid uppdateringar.
  • Stöd för HTTPS.

Nackdelar

  • Begränsad till statiska webbplatser.
  • Saknar stöd för serverbaserad kod.
  • Ingen inbyggd databas.
  • Kräver grundläggande kunskaper i Git vid publicering via Git.

Arbetsmetod för publicering

Webbplatsen utvecklas lokalt i Visual Studio Code. Filerna versionshanteras med Git och skickas sedan till ett repository på GitHub.

  1. Skapa ett repository på GitHub.
  2. Skapa och redigera webbplatsens filer lokalt.
  3. Lägg till ändringarna med git add.
  4. Spara ändringarna med git commit.
  5. Skicka ändringarna till GitHub med git push.
  6. Aktivera GitHub Pages under Settings och Pages.
  7. Välj main som publiceringsbranch.

När GitHub Pages är aktiverat publiceras webbplatsen automatiskt när nya ändringar skickas till den valda branchen.
